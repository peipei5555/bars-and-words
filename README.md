# Bars & Words

ヒップホップの歴史と歌詞表現から、実際に使える英会話を学ぶ個人用アプリ。

スマートフォンのブラウザで開き、ホーム画面に追加するとアプリのように使えます。
電波が無い場所（電車内など）でもそのまま動きます。

## 中身

| モード | 内容 |
|---|---|
| ワールドツアー | 1973年ブロンクスから現在まで10の時代を英語で読み、バトルに勝つとクリア |
| スラング | 63語。意味・語源・使う場面・例文つき |
| 発音・縮約 | `gonna` `tryna` `imma` `'em` など28個＋音のつながり8個 |
| 音楽を語る | 会話29組。A の発言と B の返しが対で入っている |
| 知識クイズ | 31問。英語で出題される |
| 通勤モード | 20/40/60分を選ぶと、シャドーイング→単語カード→会話ドリル→クイズが自動で流れる |

案内役のキャラクター **MC Fresh** が進行を担当し、時代をクリアするたびにその時代の衣装に着替えます。

## 歌詞と音源について

**歌詞の本文と音源はこのアプリに含まれていません。** 著作権で保護されているためです。

代わりに次の方針をとっています。

- 歌詞に出てくる表現は**単語・数語の単位**で扱う
- **例文はすべて書き下ろし**。歌詞の引用ではない
- 原文を読みたいときは **Genius** への検索リンクから外部サイトへ
- 曲を聴くときは **Spotify / YouTube** への検索リンクから外部サイトへ

歴史の記述は事実にもとづく解説であり、既存の文章の複製ではありません。

## データについて

学習記録はブラウザ内（localStorage）にのみ保存されます。
**外部への送信は一切ありません。** ログインも不要です。
記録は端末ごとに独立しているため、スマートフォンとPCで別々に貯まります。

## 内容を増やすには

`data/` の中のファイルを編集するだけで、一覧にもクイズにも自動で反映されます。

| ファイル | 中身 |
|---|---|
| `data/history.js` | 時代の解説・人物・用語・聴く曲 |
| `data/slang.js` | スラング |
| `data/pronunciation.js` | 発音の縮約・リンキング |
| `data/phrases.js` | 会話フレーズ |
| `data/quiz.js` | 知識クイズ |
| `data/commute.js` | 通勤モードの教材 |
| `data/character.js` | MC Fresh の見た目とセリフ |

## ローカルで動かす

任意の静的サーバーで配信してください。ビルドは不要です。

```bash
npx serve .
```

## 技術メモ

- 依存パッケージなし。HTML / CSS / JavaScript のみ
- キャラクターと背景はすべて SVG と CSS で生成（画像ファイルを使っていないため拡大してもぼやけない）
- Service Worker により初回アクセス後はオフラインで動作
- 読み上げはブラウザの Web Speech API を使用（端末に入っている音声で再生されます）
