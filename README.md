# Bars & Words

好きなラップに出てくる英単語のうち、**知らない語だけ**を覚える個人用アプリ。いまはエミネム10曲・278語。

## 流れ

1. **仕分け** — 単語を見て「知ってる／知らない」を選ぶ
2. **確認テスト** — 「知ってる」と答えた語が本当に分かるか4択で確かめる。間違えたら学習へ回る
3. **学習・復習** — 知らない語は意味と例文を見てからテスト。正解するたびに次の出題が 1日→3日→7日→16日… と延びる。7日後の出題に正解したら「覚えた」

## 構成

| 場所 | 中身 |
|---|---|
| `index.html` `app.js` `app.css` | 本体（ビルド不要の静的ページ） |
| `data/eminem.js` | 単語データ。歌詞本文は載せず、例文は書き下ろし |
| `audio/` | OpenAI TTS で事前生成した発音・例文の MP3 と `manifest.js` |
| `bgm/` | 曲ごとのBGM（ACE-Step で生成） |
| `assets/` | キャラクターの静止画と待機ループ動画 |
| `tools/` | 音声生成 `generate-audio.mjs`、BGM整音 `master_bgm.py` |

学習記録は端末の localStorage にだけ保存される。

`sw.js` は旧版（ともやの家）のキャッシュを消すためだけに置いている。旧版を開いた端末がすべて更新された頃に外してよい。
